## Brand & Style

This design system embodies high-velocity financial intelligence, combining the institutional precision of global banking infrastructure with the rapid, predictive agility of modern machine intelligence. The aesthetic merges **Corporate / Modern** discipline with **tactile micro-surfaces** and **restrained glassmorphism**, prioritizing immediate legibility, high data density, and clear transaction tracking.

### Brand Attributes
- **Predictive & Authoritative:** High-contrast type scales and crisp visual hierarchy establish instant credibility for high-stakes capital flows and autonomous reconciliation workflows.
- **Electric & Focused:** Pristine neutrals (#FFFFFF, #F8FAFC) accented by vibrant blues generate an active, working surface that directs user focus directly to margins, yield anomalies, and checkout velocity.
- **Dual-Persona Cohesion:** A unified foundational infrastructure seamlessly flexes between high-context merchant balance sheets (dense layouts, dense tabular data, ledger states) and frictionless customer payment sheets (express checkout flows, tokenized verification, tactile micro-interactions).

### Visual Metaphor
The interface operates as an algorithmic command center. Surfaces feel milled, crisp, and elevated through hair-thin borders (#E2E8F0) and microscopic tonal shifts rather than dramatic blurs or heavy skeuomorphic extrusions. Glass effects are functional rather than decorative, reserved exclusively for floating navigation rails, modal overlays, and transient status banners.

## Colors

The palette establishes absolute functional clarity. Neutral environments maintain crisp contrast ratios meeting WCAG 2.1 AAA for core body text and WCAG AA for secondary UI elements.

### Color Architecture
- **Primary Canvas & Surfaces:** Pure White (`#FFFFFF`) serves as the base layer for interactive cards, data tables, and modal dialogs. Slate Foundation (`#F8FAFC`) anchors app shells, viewports, and page-level canvas wrappers. Tonal borders use Light Slate (`#E2E8F0`).
- **Brand & Action Signals:** Electric Cobalt (`#2563EB`) acts as the interactive driver for primary buttons, selection states, active tabs, and predictive trigger highlights. Sky Shift (`#3B82F6`) provides responsive hover and focused border states.
- **Executive Anchors:** Midnight Slate (`#0F172A`) commands high-level titles, brand anchors, primary action buttons in merchant contexts, and dark navigation surfaces. Ink Navy (`#1E293B`) defines high-prominence headers and structural dividing blocks.
- **AI & Automation Accent:** Indigo Catalyst (`#6366F1`) signifies autonomous AI processing, auto-routing rules, and predictive checkout actions.
- **Financial Status Semantic Tones:**
  - **Success / Positive Delta:** Emerald (`#10B981`) paired with light wash (`#ECFDF5`) and text (`#047857`) for finalized settlements, positive cashflow, and verified transactions.
  - **Pending / In-Transit:** Amber (`#F59E0B`) with tinted surface (`#FFFBEB`) and text (`#B45309`) for manual reviews, escrow periods, and gateway syncs.
  - **Critical / Chargeback / Refund:** Rose (`#EF4444`) with tinted surface (`#FEF2F2`) and text (`#B91C1C`) for disputes, failed webhooks, API failures, and cancellations.

## Typography

The typographic system utilizes a paired dual-sans hierarchy optimized for fast numerical scanning and high-clarity dashboard navigation.

- **Display & Headings (Plus Jakarta Sans):** Crafted with balanced geometric proportions, open apertures, and subtle contemporary cuts. Conveys forward-looking technical competence across KPI totals, modal titles, and section headers.
- **Interface & Readability (Inter):** Serves all utility and transaction functions. Standardizes on fixed tracking and explicit vertical metrics to prevent baseline shifts when swapping values dynamically.
- **Numerical Ledger Standard:** All financial amounts, currency calculations, table data cells, exchange rates, and timestamps must use `font-feature-settings: "tnum" 1, "cv05" 1, "zero" 1` to ensure strict vertical tabular alignment across streaming ledgers.

## Layout & Spacing

The layout model uses a multi-tier responsive grid system based on an absolute 8px baseline rhythm (with 4px micro-steps for compact data rows, badges, and controls).

### Grid Infrastructure
- **Desktop (1280px and above):** 12-column dynamic fluid grid with `margin-desktop` (2.5rem / 40px) and `gutter` (1.5rem / 24px). Accommodates collapsed/expanded navigation sidebars, fixed analytical charts, and real-time transaction feeds without table clipping.
- **Tablet (768px – 1279px):** 8-column layout with `gutter-sm` (1rem / 16px) and `margin` (1.5rem / 24px). Multi-column ledger tables convert to dual-column priority summary views or horizontally scrollable cards.
- **Mobile (320px – 767px):** 4-column layout with `margin-mobile` (1rem / 16px) and `space-sm` (0.5rem / 8px) column gutters. Checkout flows, biometric confirmation sheets, and payment sheets become full-width fixed-drawer interfaces with sticky CTA bars.

### Density Scales
- **Compact Density (Merchant Ledgers):** Standard card padding is reduced to `space-md` (16px), row heights clamp to 40px, and field gaps follow `space-sm` (8px).
- **Comfortable Density (Customer Checkout & Onboarding):** Card padding scales to `space-xl` (32px), with element gaps set to `space-md` (16px) for unhindered touch interaction.

## Elevation & Depth

Visual depth is achieved through structural layering, hairline containment borders, and diffuse micro-shadows that keep the interface grounded and clean.

### Depth Hierarchy
- **Level 0 (Base Canvas):** Background surface `#F8FAFC`. Zero elevation, zero shadows.
- **Level 1 (Card & Section Containers):** Background `#FFFFFF` with a 1px solid border in `#E2E8F0` and subtle dual drop shadow: `box-shadow: 0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1)`. Used for standard dashboard metrics, tables, and settings blocks.
- **Level 2 (Interactive Flyouts & Menus):** Background `#FFFFFF` surrounded by `#E2E8F0` and `box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1)`. Used for dropdown menus, popovers, and quick-filter trays.
- **Level 3 (Modals & Overlays):** Background `#FFFFFF` paired with `box-shadow: 0 20px 25px -5px rgb(0 0 0 / 0.1), 0 8px 10px -6px rgb(0 0 0 / 0.1)`. Backing scrim utilizes `#0F172A` at 40% opacity with a subtle `backdrop-filter: blur(4px)`.
- **Restrained Glassmorphism (Floating Utility Bars / AI Processing Banners):** Background: `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(8px)`, enclosed in a 1px border of `rgba(226, 232, 240, 0.8)`. Keeps active financial transactions visually top-of-mind without occluding the data plane below.

## Shapes

The design system implements a **Rounded** shape language (`roundedness: 2`), balancing software approachability with enterprise stability.

### Corner Radius Mapping
- **Base Components (`rounded`: 0.5rem / 8px):** Primary buttons, input fields, dropdown toggles, and table selection rows. Provides crisp structural boundaries while softening data-heavy interactions.
- **Containers & Modals (`rounded-lg`: 1rem / 16px):** Metric panels, payment cards, ledger containers, and modal sheets. 
- **Large Contextual Overlays (`rounded-xl`: 1.5rem / 24px):** Slide-over drawer panels, customer pay-sheets, and empty-state illustrations.
- **Status Pills & Micro-Indicators (`rounded-full`: 9999px):** Status badges, tag filters, user avatars, verification checkmarks, and AI copilot pill prompts.
